## 🐛 TROUBLESHOOTING QUICK LINKS

| Issue | Solution |
|-------|----------|
| "npm is not recognized" | Install Node.js from nodejs.org |
| "Port already in use" | Change PORT in backend/.env |
| "Cannot find module" | Run npm install again |
| "Database error" | Run `npx prisma migrate reset` |
| "WebSocket fails" | Check CORS_ORIGIN in backend/.env |
| "Nothing happens on npm run dev" | Check console for errors |

**Full troubleshooting guide**: See SETUP.md
